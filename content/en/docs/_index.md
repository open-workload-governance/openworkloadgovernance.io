OWG uses a generic **Workload** object to describe ownership, identities, resources, provided
capabilities, dependencies, access intents, and governance requirements.

1. Read [Workloads](concepts/workloads/) to understand the object and the questions it answers.
2. Read [References](concepts/references/) for named and direct external references.
3. Explore the [Workload Specification](specification/) and its draft boundaries.
4. Follow the [Shop API Example](examples/) to connect the fields to a service.

All specification pages describe **version 0.1 Draft**, with status **Proposal**.
