Open Workload Governance is presented here as a proposal for vendor-neutral governance ownership.
This starter publishes English documentation; it is not an identity platform or governance service.

## Now: Documentation Foundation

- Workload Specification 0.1 Draft with named and direct external references.
- Ownership, approvers, classification, identities, and resources.
- Provided APIs, scopes, dependencies, access intents, and governance requirements.
- A downloadable Workload example and an independently buildable website.

## Next: Review The Contract

Confirm the normalized identities representation. Define required fields, workload types, reference
rules, dependency matching, classifications, and shared-resource handling. Agree how the ownership
approver list interacts with the governance approver list.

Specify access-intent enforcement, change-management integration, backup-owner representation, and
recertification evidence. The fields now appear in the example, but their operational semantics
remain open. Decide any HTTP contracts before publishing an API or conformance tests.

## Later: Publish And Collaborate

Establish repository ownership, contribution guidelines, and licenses. Add CI, deployment previews,
accessibility reviews, and versioned specification releases. Hosting and DNS are not configured by
this starter.

No official community links, implementation claims, or vendor partnerships are assumed.
